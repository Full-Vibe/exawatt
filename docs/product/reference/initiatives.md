# Initiatives

An Initiative is a durable high-level goal or area of responsibility.

Initiatives are not cron jobs and not narrow tasks. They are the strategic containers agents work against over time.

Examples:

- Grow Exawatt investor pipeline
- Maintain this codebase
- Plan Art Basel week
- Monitor churn risk and recommend interventions
- Run weekly product marketing experiments

Good Initiatives give agents enough context to evolve, research, coordinate, and act without reducing them to task repeaters.

## Terminal projection

The Terminal ribbon currently presents Session-backed tabs as
Initiative-shaped work because the operator needs to switch by goal, not by
process. This is a migration projection: it is usually one-to-one with an Agent
and Session today, while the durable Initiative primitive remains planned. A
future Initiative may coordinate many Agents and Sessions over time.

Projects remain the first grouping level in the ribbon. Selecting a Project
expands its Initiative-shaped tabs; an inactive Project stays compact unless
manually kept open. Subagents aggregate into the parent work's status rather
than automatically becoming peer Initiatives.
