# Product Reference

This folder holds public-safe product concept explainers.

Use `docs/product/reference/` for deeper explanations of concepts that may become public documentation but are not step-by-step customer guides yet. Use `docs/product/guides/` for customer-facing how-to material.

`docs/product/concepts.md` remains the canonical vocabulary source. If a reference doc changes what a concept means, update `docs/product/concepts.md` in the same change.
