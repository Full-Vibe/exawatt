title: Escape takes you back one step
---

Escape now backs out one step at a time, from the menu or dialog on top
down to the view you opened. It works the same in Settings, Team and Fleet.

## Improvements

- Right-click menus and ⌘K offer the same commands, including Mark unread.
- In ⌘K, the best match comes first, even when a command you can't use right
  now also matches.
- After an update, Exawatt shows you what's new.
- An empty Chatter shows how your agents start talking.
- The v2 Fleet view (Settings, Fleet view) responds to every agent you point
  at or press, including delegated ones.
- Fleet draws only when something changes, and nothing while your screen is
  locked or the window is hidden.

## Fixes

- Opening Exawatt again brings the running copy forward instead of starting
  a second one. If Exawatt runs from outside Applications, it offers to move
  there.
- Resume no longer fails with "This Session already has a running process",
  and reloading the window never starts an agent twice.
- A slow start shows the progress screen instead of a blank window.
- Settings no longer repeats each page's title above a row of links.
- Taking a screenshot for feedback keeps your place in the draft.
