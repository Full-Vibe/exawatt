Launch, resume, pick models, and see Qwen Code history alongside Claude Code,
Codex, Gemini and Grok.

## New

- **Connect a server in one screen.** Pick a server, approve send access in
  one click, and find connected coworkers in one Remote home. Cancelling a
  Connect closes everything it opened.
- **Settings > Safety.** An optional guard that refuses an agent's process
  kill when it would take down your apps, other agents or too many processes
  at once. Off by default.

## Improvements

- **⌘T opens instantly.** The launcher paints at once and rechecks agents in
  the background. Start no longer waits on unrelated agents.
- **Better on battery.** The Fleet view stops animating on battery and when
  the screen locks.
- **The window heals itself.** If a helper process is killed, the window
  recovers on its own, and asks to Reload or Quit only when it cannot.
- The counts bar and the Fleet board use the same status words.
- A read that fails says so, with Retry, instead of looking empty.

## Fixes

- Paused agents read as paused everywhere, never as failed. Closing a tab
  while its agent is starting cancels the start.
- Saved workspace, session, usage and plan records that cannot be read are
  kept and retried, never written over. Browser storage survives a relaunch.
- Grok usage survives a restart, and usage the previous version dropped is
  read again.
- Cancelling ⌘Q leaves everything running.
