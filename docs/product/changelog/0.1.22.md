Your Claude Code and Codex agents in one Project message each other by name.
Every message shows up in Team's Chatter tab, with whether it arrived. Add
your own line with Send as operator.

## New

- **Direct a group.** Drag around agents on the Fleet board, press ⌘D and
  type one line. Each agent shows whether it got it.
- **Your projects are already here.** The Start screen lists the folders
  Claude Code, Codex and Antigravity already work in. One click opens one,
  and nothing in those apps changes.
- **Gemini joins the roster.** Start it with ⌘T beside Claude Code and Codex,
  with a guided Google sign-in.
- **Every agent has a name**, like claude-1, so you and your other agents can
  reach it.
- Exawatt now counts, anonymously, whether a new install opens a project and
  starts an agent, so we can see where people get stuck. The exact events are
  on the Privacy page, and Settings turns them off.

## Improvements

- Restarting or updating brings back what you were holding: the Fleet camera
  and any feedback you had not sent.
- Signing in to an agent is one step inside Exawatt, for every agent.
- Codex, Claude Code, Grok and Qwen setups with a custom home folder are
  found.

## Fixes

- Restart to Update and Quit say what they are waiting for, finish within a
  set time, and can be cancelled. Nothing hangs on "Closing Exawatt…".
- Agent marks stay legible on light themes, and Team tiles and Chatter show
  the same mark for the same agent.
- A model is marked unavailable only when the agent's own list says so.
- Shift+arrow on the Fleet board extends a selection without jumping to
  another Project.
- A dismissed notice stays dismissed.
