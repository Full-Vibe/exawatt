# 0041: Delegation evidence precedes representation and launch guidance

- Date: 2026-09-18
- Status: proposed; implementation and visual acceptance remain gated
- Roadmap: ENG-023 D6 / D8, BUG-094 / BUG-133 half 1 / BUG-134

**Separate what the harness knows, what the source proves, and what the UI draws.**

The operator requested holistic repairs. Two existing boundaries lose meaning:
Fleet filters parents and caps child metadata before inspection; launch plumbing
composes hooks and tasks but supplies no natural-language Exawatt context.
Patching individual glyphs or prefixing the operator's task leaves those ownership
problems intact. Decision `0040` already separates coverage from turn truth.

Proposed contract:

- Source adapters and the existing lifecycle owner publish scoped child identity,
  immediate-parent evidence and observation coverage. Unknown lineage is not an
  invented edge; navigation to the known root is a separate fact.
- Pure shared selectors own the complete census, entity-level query conjunction,
  match/context sets and summaries. Geometry partitions matching children into
  bounded individual/overflow/aggregate buckets. Inspection resolves the full
  roster. Child counts never inflate commandable Agent counts or Consumption.
- Main composes one bounded optional environmental contribution; source adapters
  apply it without replacing effective provider/user instructions or permissions.
  The operator task, Types and environmental guidance retain separate ownership.
- A renderer-safe receipt describes only Exawatt-authored text, bound to durable
  Session and launch generation. Prepared, supplied and verified model adoption
  are different evidence. Resume, compaction and child inheritance each need
  proof; argv acceptance alone cannot establish adoption.
- Use existing launch, Session inspection and Agent Sources surfaces. Quiet
  place-of-use coverage clarifies partial/unknown observations without another
  status light. New visual grammar requires DOM/R3F gallery review.

Rejected alternatives: natural-language question interception; terminal keystroke
retrofit; task prefixes; rewriting provider/project configuration; retaining
unverified children as live; source-wide health relabeled as root health; separate
renderer censuses; removing graphic budgets; marketing unproven support.

Consequences: this introduces a small shared evidence model and provider-specific
proof obligations, not a new orchestration service. Optional context conflicts
preserve launch with an inspectable omission. Missing source authority preserves
only independent verified children and explains coverage. D2 independent child
chat, ENG-028 Types and ENG-029 coordination remain separate work.

The [execution brief](../projects/delegation-visibility.md#2026-09-18--d6-and-d8-execution-brief-truthful-delegation-end-to-end)
is the detailed contract, provider matrix and acceptance sequence. This record
proposes architecture; it does not assert implementation or accepted visual design.
