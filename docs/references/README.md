# Visual References & Inspiration

## Film/TV References
- **Minority Report (2002)** — Gestural interface, translucent panels, spatial data manipulation. Designed by John Underkoffler (Imaginary Forces). Key: information layered in space, direct manipulation, large-format displays.
  - Concept art: https://imaginaryforces.com/project/minority-report
  - HUDS+GUIS breakdown: https://www.hudsandguis.com/home/2010/12/05/minority-report
  - Clip: https://www.youtube.com/watch?v=NwVBzx0LMNQ

- **Star Wars: Thrawn** — Imperial command bridge aesthetic. Dark backgrounds, holographic blue/green tactical displays, clean grids showing fleet positions. The "calm authority" feel — information density without chaos.

- **Iron Man / JARVIS** — Holographic HUD overlays, radial menus, floating data panels. More playful/energetic than Minority Report. Good reference for the "focus on one agent" deep-interaction mode.

- **The Expanse** — Realistic near-future military command UIs. Flat panels with depth cues, status grids, threat indicators. Probably the most realistic sci-fi UI reference.

## Game References
- **EVE Online** — Fleet management, overview panels, multi-window information density. Handles 1000+ entities on screen.
- **Stellaris** — Galaxy map with zoom levels, entity status at a glance. Good model for fleet → individual transition.
- **XCOM** — Mission control base view. Status cards, resource bars, personnel management. The "morning check-in" feel.
- **Factorio** — Information density done right. Every signal means something. No decoration for decoration's sake.

## Real Tool References
- **Datadog** — Dashboard tiles, real-time metrics, status heatmaps. Dense but readable.
- **Grafana** — Time-series panels, flexible layouts. Good for the timeline/activity view.
- **Linear** — Clean, keyboard-first, fast. The gold standard for "tool that doesn't waste your time."

## Design Principles (from references)
1. **Dark background, light data.** Every reference uses dark themes. Information glows against darkness.
2. **Blue/cyan/teal as primary.** Nearly universal in sci-fi command UIs. Warm accents (amber/red) for alerts.
3. **Translucency and layering.** Panels have depth even in 2D. Background elements visible through foreground.
4. **Subtle animation = life.** Pulsing borders, flowing particles, breathing glow. Static = dead.
5. **Information hierarchy through brightness.** Critical info is bright. Context is dim. Nothing is invisible.
6. **Monospace/technical typography.** Numbers and status in monospace. Headers in clean sans-serif.
